## 一、受影响页面 / 路由

- `/`：电脑端本地应用首页，用于进入项目、查看会话和开始工作流。
- `/capture/:sessionId`：手机采集页面，用于在同一局域网内拍照并上传图片到电脑端。
- `/editor/:problemId`：电路图编辑和拓扑修正页面，用于查看候选拓扑、修正节点连接、元件类型和参数。
- `/jobs/:jobId`：任务状态页面或接口，用于查看图像处理、分析、评测等任务的排队、运行、完成或失败状态。
- `/results/:problemId`：解题结果页面，用于展示分析结果、等效电路图、LaTeX 公式、图形标注、警告信息和知识点解释。
- `/benchmark`：本地评测页面，用于运行 30 道题 benchmark 并查看分层指标。

## 二、关键交互验证

- 用户用手机扫描电脑端二维码，并上传电路图片。
- 电脑端成功接收图片，并创建图像处理任务。
- 系统展示候选拓扑和可疑点，例如低置信度元件、疑似断线、未连接端口等。
- 用户修正节点连接、元件类型和元件参数。
- 用户确认电路图，并触发自动分析。
- 系统展示直流等效电路图和交流小信号等效电路图。
- 系统返回结构化分析结果和展示结果。
- 用户导出 LaTeX 公式和解题步骤。
- 用户运行 30 道题 benchmark，并查看识别、拓扑、分析、输出等分层指标。

## 三、边界情况

- 手机无法访问电脑端本地服务，例如不在同一局域网或防火墙阻止访问。
- 二维码会话过期，或一次性上传 token 被重复使用。
- 上传图片格式不支持、图片过大、图片方向错误或图片损坏。
- 图像处理得到的候选拓扑存在缺失端口、断线、低置信度元件或无法确认的节点连接。
- 用户提交的电路图存在悬空节点、未连接端口、缺失参数或重复元件编号。
- 分析策略无法自动判断题型，需要用户手动选择分析策略。
- SymPy / Lcapy 求解超时或表达式复杂度过高。
- 本地 SPICE / ngspice 工具不可用，导致数值校验无法执行。
- LaTeX 公式渲染失败，或公式变量无法追溯到结构化分析结果。
- 批量评测时某一道题失败，但整套 benchmark 应继续运行并记录失败原因。

## 四、关键端到端路径

```text
手机拍照
→ 本地上传
→ 生成候选拓扑
→ 用户修正
→ 确认电路图
→ 自动分析
→ 展示直流/交流等效电路图
→ 导出 LaTeX 公式和解题步骤
```

```text
确认后的电路图
→ 选择分析策略
→ 生成直流/交流等效电路图
→ 建立方程
→ 求解目标参数
→ 展示公式、标注和知识点解释
```

```text
benchmark 测试题
→ 读取标准答案 / 多层 ground truth
→ 运行识别、拓扑、分析和输出流程
→ 生成分层评测指标报告
```

## 五、测试分层

### 1. 数据结构测试

- 合法和非法的类型化电路图。
- 合法和非法的元件定义。
- 结构化分析结果字段完整性。
- 题目样例和 ground truth 的格式校验。

### 2. 图像与拓扑测试（已取消，不执行）

- 元件类型识别准确率。
- 节点连接识别准确率。
- 参数识别或参数辅助定位准确率。
- 低置信度和可疑点召回率。

### 3. 分析引擎测试

- 直流等效电路图是否正确。
- 交流小信号等效电路图是否正确。
- 静态工作点方程是否正确。
- 增益、输入电阻、输出电阻等目标参数是否正确。
- SymPy / Lcapy / SPICE 交叉校验是否一致。
- 符号求解超时后是否能返回部分结果和警告。

### 4. 展示输出测试

- LaTeX 是否能够正常渲染。
- 公式变量是否能追溯到结构化分析结果中的节点、支路或元件。
- 解题步骤是否覆盖关键知识点。
- 等效电路图上的标注是否与方程和结果一致。

### 5. 用户界面与端到端测试

- 手机扫码上传图片。
- 电脑端显示候选拓扑。
- 用户修正节点、元件和参数。
- 用户触发分析。
- 页面展示等效电路图、公式、标注和步骤解释。
- 用户导出 LaTeX。
- 用户运行 30 道题 benchmark 并查看报告。

## 六、第一版通过线

识别层：

- 元件类型识别准确率不低于 90%。
- 元件参数识别准确率不低于 85%。
- 节点连接识别准确率不低于 85%。
- 低置信度 / 可疑点召回率不低于 90%。

- 用户确认电路图后，目标求解量正确率不低于 90%。
- 等效电路生成正确率不低于 85%。
- 关键方程正确率不低于 85%。

输出层：

- 步骤说明覆盖关键知识点不低于 85%。
- 用户修正后端到端成功率不低于 90%。
