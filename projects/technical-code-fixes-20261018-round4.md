## 1. 用户要求与处理

| 要求 | 处理 |
|---|---|
| 电解电容阴极符号弯曲方向不对 | `BuildCapacitorPolarized` 负极曲板改为标准圆弧（圆心 (38,0)、半径 30），弧顶移到 (8,0) 并凸向正极直板，负极引线接弧顶；`+` 标记保持在正极直板一侧 |

## 2. 符号几何修改（`Models/SymbolGeometry.cs`）

### 2.1 电解电容（`BuildCapacitorPolarized`）

- 正极直板（x=-6）与正极引线不变，`+` 标记仍位于正极板旁。
- 负极曲板由手调折线改为圆弧采样（新增 `CircleArcPoints` 辅助函数），弧顶 (8,0) 最靠近正极直板，两端 (14,±18) 向负极端张开；负极引线从弧顶 (8,0) 引至引脚 (35,0)。
- 此前实现弧顶 (14,0) 朝负极端、两端 (8,±18) 靠近正极板，弯曲方向相反，即用户指出的错误。

### 2.2 MOSFET（`BuildMosfet`，四类）

- 栅极板 x=1.5、长度 = D/S 横线间距（y=-18..18），与沟道分离；栅极引线仍接引脚 G(-35,0)。
- 沟道 x=8：增强型为 3 段断续竖线（中点 -18 / 0 / +18，各段半长 7.5），耗尽型为整段实线（y=-25.5..25.5）。
- D/S 横线接在顶部/底部沟道段的**中点**（y=∓18），沟道段向横线外伸出；D/S 引线在 x=20 竖直引至 ±35 引脚。
- 衬底横线 (8,0)→(20,0)→(20,18) 与源极横线/源极引线短接，短接处新增实心连接点 `Dot(20,18,1.7)`；衬底箭头改为横线靠沟道一侧的实心三角（N 指向沟道、P 背离沟道）。
- 引脚仍为 G(-35,0) D(20,-35) S(20,35)，未改 `CircuitElement.cs`。

### 2.3 JFET（`BuildJfet`，N/P）

- 删除旧实现中 MOSFET 式的独立“栅极条”（JFET 为 PN 结栅，标准符号无绝缘栅极条）：栅极引线直达沟道，实心箭头贴住沟道中点。
- 沟道 x=8、半高 24（略长于 D/S 横线间距）；D/S 引线先在 x=20 竖直引出，再经水平短接横线（y=∓18）接至沟道上下端，符合标准画法（旧实现把 D/S 引线直接叠在沟道延长线上）。
- 箭头方向：N 沟道尖端指向沟道（x=8）、P 沟道尖端背离沟道（x=-1）。
- 引脚不变。

## 3. 测试（`tests/SymbolChecks/Program.cs`）

- 更新 JFET/MOSFET 沟道 x 期望值（20→8、14→8）。
- 新增断言：
  - 极性电容负极曲板弧顶凸向正极直板（弯曲方向验收项），弧顶位于 (8,0)；
  - MOSFET D/S 横线接在沟道顶/底段中点（±18），沟道段伸出横线之外；
  - MOSFET 增强型 3 段 / 耗尽型整段，栅极板与沟道分离（间隙 ≥ 4）；
  - MOSFET 衬底-源短接处存在实心连接点；
  - JFET 沟道左侧无独立栅极条，D/S 横线接至沟道上下端。
- 新增辅助函数 `HasTwoPointLine`、`HasVerticalSegmentInXRange`、`VerticalExtentAt`。
