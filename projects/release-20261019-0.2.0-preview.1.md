## 2. 发布构建口径

- 源码基线：Git `36f1a90` + 当前工作区未提交改动（发布时 `git status` 119 项；应用源码快照聚合 SHA256 `B81E2851E5D9DE3E1C1C63AF275E7691F078072C944E4ED2B924459774345F4E`）。未建立 Git 标签。
- 构建：`dotnet build apps/desktop-winui/CircuitAssistant.csproj --no-restore`（Debug 验证）与
  `dotnet publish apps/desktop-winui/CircuitAssistant.csproj -c Release -r win-x64 --self-contained true -p:Platform=x64 -p:PublishTrimmed=false -p:WindowsAppSDKSelfContained=true -o <发布目录>`。
- `PublishTrimmed=false`：项目文件在 Release 下默认 `PublishTrimmed=true`，但 WinUI 3 未打包应用裁剪后会丢失 XAML/JSON 序列化所需类型并产生 IL2026/IL2104 警告；发布必须显式关闭裁剪（0.1.0-preview.1 的发布产物同为未裁剪，528 个运行文件的数量与之一致）。
- `WindowsAppSDKSelfContained=true`：发布包自带 Windows App SDK 运行时（`Microsoft.WindowsAppRuntime.dll`、`Microsoft.ui.xaml.dll`、语言资源等），无需目标机安装 WinAppSDK。
- 最终发布构建 0 警告 / 0 错误。

## 4. 本阶段能力变化（相对 0.1.0-preview.1）

- 新增**耗尽型 NMOS/PMOS 与 N/P 沟道 JFET** 单管放大器教学求解（共源、共源 + Rs、共源旁路、共漏、共栅）；JFET 使用 Shockley 方程 `ID=IDSS·(1−VGS/VGS(off))²`，增强/耗尽 MOS 使用 Level-1 平方律；检查器可编辑 MOS 的 K/λ 与 JFET 的 IDSS，并随工程保存/读回。
- 新增**元器件工作区物理核验**（2026-10-19）：BJT 分压偏置在无发射极电阻时改用含基极负载的偏置方程，BE/BC 结条件统一校验；MOS/JFET 用分段模型与直流负载线核验；二极管/FET 非有限值归入无效状态。真实截止/饱和与数值失败分开诊断，教学显示仍按教材估算法两位小数回代。
- 保留并强化第七~九轮教学能力：教材估算法两位小数显示与 DC/AC 推导分组、BJT 信号源内阻 Rs/电解输入耦合电容/Aus、r_bb′/r_be 可调、公式 Win2D 原生排版、四格式报告导出。
- 详见发布包内 `RELEASE-NOTES.md` 与 `projects/fet-depletion-jfet-strategies-20261019.md`、`projects/operating-region-validation-20261019.md`。
