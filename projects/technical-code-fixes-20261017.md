## 3. 求解校验、失败与调度

- 工作台在独立元件/导线快照上后台执行提取、校验、分类和求解，不让提取器回写用户编辑对象。
- 接入 ElectricalNetlist.Validate：短路、悬空/分离网络、非法值与单位会阻止求解；自动参考地给出提示。
- UI 服从 IsSuccess，不再无条件显示成功；修改期间的迟到结果丢弃；默认指标改为未求解占位，去掉固定共射预览。
- 原生入口有取消等待按钮和 15 秒等待上限，规模限制 512 个元件/4096 根导线；MNA 限 256 个矩阵变量。超时/取消等待不保证强制终止所有底层同步计算。
- 单位转换统一经 NetlistExtractor.ConvertToBaseSi，区分前缀大小写并拒绝错误单位；极小非零值不再在数字格式化时被直接写成零。提取阶段保留非法单位为无效支路数值，连通分析仍可完成；正式 Validate 会在求解前报告并阻止该输入。

## 4. 策略修订

| 策略 | 修改 |
|---|---|
| 基础 MNA | 加独立电流源右端印记，方向与画布向上箭头一致；不支持器件明确拒绝；奇异/病态主元、非有限结果返回失败；首节点电压不再当成增益 |
| MOS/JFET | 识别后进入明确的不支持策略，停止通过不含晶体管印记的 MNA 输出错误答案 |
| RC/RL | 只接受已检查的单源、单储能元件、串联电阻闭合回路；缺件/并联/加载/多源不再直接求和或补默认值；RC 高通使用对应传递函数与相位；RL 步骤不再输出电容电压结果 |
| RLC | 限各一个 R/L/C 的标准串/并联结构；并联可用电流源激励，复杂网络拒绝；非正/非有限值不钳成默认值；相对临界阻尼判断和标准半功率频率 |
| BJT | 限单 NPN 放大模型，必要偏置和外接负载从连通关系识别，缺少必要偏置或有未知支路时拒绝；没有外接负载按开路处理；耦合/旁路不再按 C1/C2/Ce ID 补默认值；非放大区停止小信号推导 |
| BJT 公式 | rbe 改用 IEQ；未旁路发射极与集电极反馈采用对应方程；共基极计入分压负载并去掉教材固定答案；缺高频参数的共基极明确显示未求解，共射高频标为模型估算；去除电阻/电流最小值钳位，避免合法小参数被改写 |

本轮没有新增通用 PNP/FET/非线性仿真器、任意拓扑 Req、受控源/动态 MNA 或完整频率扫描。限制范围是为了避免在模型不成立时给出看似有效的结果。

## 5. 编辑器与配套修订

- 交流幅值保留 DisplayNumber/UnitSymbol，频率改用独立 FrequencyHz，在检查器和工程文件中读写；模板宏不再把频率写进幅值字段。
- 二极管“半导体管”分类补齐；数值编辑获得焦点时记录撤销快照，撤销后同步宏；新建/打开/关闭清理历史。
- 删除父导线时递归移除 WireTap 子线，减少残留无效父引用。
- Loaded 重入不重复注册画布事件；选中元件的属性监听在切换时解除。
- MathFormulaView 按完整数学命令 token 替换，修正 le/leq、ge/geq 等前缀冲突；仍为 Unicode 展示，没有新增完整 TeX 排版引擎。
- SPICE 输出使用数值节点（地为 0）、不依赖系统区域的数值文本，电流源方向与画布一致；导出前校验并拒绝未覆盖器件。模型卡和仿真执行仍未集成。
- 独立 API 的捕获页显式返回 HTMLResponse，并对会话/token 的 URL 内容编码；未做手机或浏览器验证。
