# 产品设计现状：WinUI 电路教学辅助系统

> 原设计日期：2026-05-27；按源码修订：2026-10-17。原始探索、路线比较和视觉愿景保存在[历史副本](archive/2026-10-17-before-winui-doc-sync/wzh-no-git-worktree-design-20260527-172528.md)，不是当前交付承诺。

## 问题与当前产品路径

产品服务电路和模拟电子技术学习：用户手工搭建电路或加载教学模板，编辑连接和参数，查看按策略生成的公式、代入和分步解释。当前入口是 Windows 原生 WinUI 工作台。

```text
新建/加载模板 → 编辑元件与导线 → C# 提取网络并分类
 → 基础教学分析 → 查看指标/复制公式 → 保存自有工程
```

原文的“从教材照片自动恢复拓扑”不再是当前路径：视觉接入安排在后续阶段；手机上传仅保留在独立 Web/Python 原型中，WinUI 未接入。

## 设计目标与实现状态

| 设计点 | 当前实现 | 尚需验证/建设 |
|---|---|---|
| 易编辑的电路图 | Win2D、符号库、参数、旋转、布线和分支 | 复杂交互一致性与真实窗口验收 |
| 可解释求解 | RC/RL、RLC、部分 BJT、有限 MNA 教学步骤 | 任意拓扑、完整 FET/PNP/非线性与错误拒绝 |
| 数学表达 | 原始 LaTeX 字符串、Unicode 转换、复制 | 完整数学排版、长公式布局 |
| 工程管理 | 自有 JSON 打开/保存/另存为、SPICE 文本 | 路径重置、脏标志、未保存提示、迁移与完整持久化 |
| 数据基准 | 独立原型中 3 个 JSON Benchmark | 30 题覆盖、原生适配、准确率报告 |
| 等效电路与报告 | 当前原生端未实现自动等效图/完整报告 | 需独立设计、实现和验证 |

## 已确定的技术形态

- 主客户端采用 C# / .NET 9 / WinUI 3，不再在网页、Electron 或 Tauri 之间待选。
- 原生编辑模型和求解网表位于 `apps/desktop-winui`，与原型 Zod CircuitGraph 分开维护。
- 求解发生在本地进程；常见教学策略使用数值计算配合公式模板，不能统称为通用符号仿真器。
- 以已支持的模板和策略边界说明能力，复杂电路、完整 EDA 和任意识别不作为已完成功能。

## 下一步设计约束

后续新增功能应围绕当前原生工作流，并先解决失败反馈、模型/参数语义和保存安全，随后补充更广求解、可靠的格式交换、完整公式及报告。保留的原型功能如要迁入桌面端，需要实际适配和验收。
