# 教材图片采集交接说明

> **状态：已终止（2026-07-23）**。视觉识别模块已取消接入，本说明中的识别数据采集、图像鲁棒性测试和 OCR/拓扑验证任务均不再执行。若仅为扩充人工录入的 Benchmark，可参考题型和版权注意事项，但不需要按视觉训练要求收集素材。

## 背景

本文原用于视觉识别阶段的教材图片采集。当前项目继续建设基础数据模型、元件库、人工结构化录入和 Benchmark，但不再从教材图片自动识别元件、连接关系或参数。

下方内容仅保留为历史交接记录，不再要求执行。

## 需要收集的内容

每道题建议准备以下材料：

```text
case-001/
  page.jpg              原始教材页或习题页截图/照片
  circuit.jpg           单独裁剪出的电路图
  problem.jpg           题干截图
  problem.txt           题干文字，可选但推荐
  solution.jpg          标准答案或解答过程截图，若有
  notes.txt             可选：题型、已知条件、求解目标等说明
```

如果没有办法整理成文件夹，也可以先直接发图，但请尽量说明每张图对应哪一道题。

## 电路图要求

电路图需要保留教材原本的信息，包括：

- 元件编号：如 `R1`、`RC`、`Q1`、`D1`、`C1`
- 元件参数：如 `10kΩ`、`0.01μF`、`12V`
- 电源和信号标识：如 `VCC`、`Vin`、`Vout`
- 节点、电流、电压标识：如题目原本标出的 `iB`、`vO` 等

不要在原始电路图上额外手动画圈、加箭头、改颜色或写说明。系统需要先看“教材原图”本身。  
如果需要人工标注，请另存一份“标注版”，不要覆盖原图。

## 题目和解答过程

题干最好一起提供。题干能帮助系统判断题目要求求什么，例如：

- 静态工作点
- 电压增益
- 输入电阻
- 输出电阻
- 等效电路
- 波形或限幅电压

标准答案或解答过程如果有，也请一起提供。它不是图像识别阶段必须的，但后续会用来建立 benchmark 的标准答案，包括关键公式、方程、最终结果和可接受的等价表达式。

## 优先题型

第一批建议优先覆盖这些模电基础题：

1. 二极管限幅、钳位或整流题
2. BJT 静态工作点题
3. BJT 共射小信号分析题
4. MOS 共源放大题
5. 带耦合电容或旁路电容的小信号题

暂时不优先收集：

- 手绘电路图
- 太复杂的综合大题
- 模拟 IC 设计题
- 纯数字逻辑题
- 图像严重模糊、遮挡、反光或缺页的题

## 图片质量建议

请尽量保证：

- 电路图、题干和参数能看清
- 图片不要过度倾斜
- 不要有明显阴影、反光或遮挡
- 如果是手机拍摄，尽量正对纸面拍
- 如果是 PDF 截图，优先使用截图而不是拍屏

第一批先用清晰图片跑通流程。后面可以再补充手机拍摄的倾斜、阴影、低对比度版本，用来测试系统鲁棒性。

## 命名建议

建议按题型和序号命名：

```text
diode-limiter-001/
bjt-bias-001/
bjt-common-emitter-001/
mos-common-source-001/
capacitor-small-signal-001/
```

如果暂时不确定题型，也可以用：

```text
case-001/
case-002/
case-003/
```

## 每道题最好附带的简短说明

可以在 `notes.txt` 里写几行：

```text
题型：BJT 共射静态工作点
来源：教材第 X 页 / 习题 X.X
已知：VCC=12V, RB=100kΩ, RC=2kΩ, β=100
要求：求 IB、IC、UCE
备注：答案里使用 VBE≈0.7V
```

不需要写得很正式，能帮助我们快速整理 benchmark 即可。

## 第一批交付目标

请先提供 3-5 道题，目标是覆盖不同类型，而不是数量越多越好。  
每道题尽量包含：

1. 原始页图
2. 裁剪电路图
3. 题干
4. 标准答案或解答过程，若有
5. 简短题型说明，若方便

这批材料会用于把当前工程里的空 `imageRefs` 补成真实教材图片引用，并开始验证教材图像识别流程。
